# Colak Health Management Website

This is the official website for Colak Health Management Ltd, a specialized healthcare staffing and management company providing comprehensive clinical support services to hospitals and medical clinics across the UK.

## Features

- Responsive design for all devices
- Modern and clean interface
- Detailed service descriptions
- Team member profiles
- Contact form with validation

## Services Offered

1. Clinical & Procedural Support
2. Patient Coordination & Liaison
3. Media, Marketing & Content
4. Compliance & Governance
5. Administrative & Reporting (remote-friendly)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- AOS (Animate On Scroll)
- PHP (for contact form)

## Setup

1. Clone the repository
2. Open index.html in your browser
